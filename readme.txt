Репозиторий с лабораторными работами

Автор: Фокин Арсений Андреевич

Структура репозитория (ветви):
- main       : этот файл readme.txt с описанием репозитория
- works-1-4  : лабораторные работы с 1 по 4 (папки Лаб1 - Лаб4)
- prolog     : программа на языке Prolog (файл prolog_my.txt)

Содержание ветки works-1-4:
В каждой работе построены диаграммы для двух примеров:
 а) алгоритм удвоения числа: ввод числа X, при X = 0 выводится
    сообщение о вводе нуля, иначе число удваивается и результат
    выводится на экран;
 б) установка Python: скачивание установщика, запуск, установка,
    проверка.

- Лаб1: ДВИ (диаграммы вариантов использования) для обоих примеров
- Лаб2: диаграмма последовательности и диаграмма деятельности
        для обоих примеров
- Лаб3: диаграмма компонентов (удвоение числа) и диаграмма
        развёртывания (установка Python)
- Лаб4: комплект UML-диаграмм из Лаб1 переведён в нотацию IDEF

Содержание ветки prolog:
- prolog_my.txt - программа на языке Prolog. Определяет, какие марки
  собирает каждый из четырёх героев, а также делает проверку (true или
  false) на правильность присвоения каждой марки герою.
  Как запустить: в SWI-Prolog выполнить consult('prolog_my.txt').,
  затем ввести запрос solve.
