Репозиторий с лабораторными работами

Автор: Фокин Арсений Андреевич

Структура репозитория (ветви):
- main       : этот файл readme.txt с описанием репозитория
- works-1-4  : работы с 1 по 4
- prolog     : программа на языке Prolog (вы находитесь в этой ветке)

Содержание ветки prolog:
- prolog_my.txt - программа на языке Prolog, 
  Данная программа определяет, какие марки 
  собирает каждый из четырёх героев, а также делает проверку(true или false) 
  на правильность присвоения каждой марки к герою.

Как запустить:
1. Запустить SWI-Prolog.
2. Загрузить программу: consult('prolog_my.txt').
3. Ввести запрос: solve.
